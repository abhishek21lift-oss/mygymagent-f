## 8. Compatibility risks

- Tailwind v4: no config file — keep it that way. New code uses `@theme`-mapped utilities + `var(--…)` tokens.
- React 19 / Next 16: zero new deps → zero peer conflicts.
- shadcn slot-CSS (`[data-slot=card]` restyles hand-rolled sections): new primitives emit the same slots.
- `tsc --noEmit` earlier failed on gitignored `.next/dev/types/routes.d.ts:158` — root-caused to a corrupted generated artifact (fixed via `rm -rf .next`); our 3 new files produce zero tsc/eslint errors.
- Dark-mode contrast: new visuals consume solved tokens only; never hardcode hex.
- Known pre-existing issues: (a) Next.js dev occasionally writes a corrupted `.next/dev/types/routes.d.ts` tail — delete `.next` and re-run; (b) `add-staff-dialog` wizard test flakes under full-suite parallel load, passes in isolation; (c) 53 lint warnings, all pre-existing.
- Remaining blockers: none. No production page redesigned; Command Center, navigation, APIs, DB, backend untouched.
